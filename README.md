# GeoDecision AI

نسخة تحافظ على تصميم الواجهة الأصلي مع إصلاحات منطقية لحساب التقييم متعدد المعايير (MCDA)، توحيد مقياس المخاطر، ومنع توليد بيانات القياس عشوائياً للمواقع الجديدة.

## التشغيل
```bash
npm install
npm run dev
```

راجع `AI_STUDIO_GUIDE_AR.md` لاستيراد المشروع إلى Google AI Studio ونشر رابط مشاركة للـ NTI.

**تنبيه:** المواقع والطبقات والقياسات الموجودة في بيانات المشروع عينات توضيحية غير موثقة. لا تُستخدم النتائج كقرار تخطيطي فعلي قبل إدخال بيانات GIS موثقة والتحقق ميدانياً.
